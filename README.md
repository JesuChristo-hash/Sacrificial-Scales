This version lets you enjoy the game WITHOUT bricking your soul or accidentally uncovering ancient evil secrets. 
Heavily inspired by Kaycee's rebalance mod, this is an even harder version, with Anti-OTK measures on by default, harder bosses, and a smaller card pool.

Let's call the current version Alpha 3.8 I suppose. Features all new Bosses, the Woodcarver, the Zealot, and Goobert as the main three, and a new Final Boss, 'The Bone Lord', with a custom sigil for its fight. Endless mode tracks your score up to 3 total runs and grades you based on how your run went. Basics were added like BGM themes, volume controls and a ton of bugfixes. Not all are resolved yet either, so the current version needs more polish, once done I'll release it as Alpha 4.0.

Beta 1.0 will follow, and have all new items I've designed but yet to implement. All are either rebalanced vanilla items like the Magical Hat and Joker Stamp, or are completely new in their mechanics, like Loaded Die and Bone Lord's Horn.
